OpenTranslate

设置

翻译只走外部接口。选择 DeepL、DeepLX 或 OpenAI 兼容服务。

翻译接口

DeepL 和 OpenAI 需要 API Key。DeepLX 的 Key 可以留空。

API Key

API Key 写入系统钥匙串。钥匙串不可用时保存在本机配置目录，权限仅限当前用户，不会写入 settings.json，也不会出现在日志里。

外观

默认跟随系统，也可以固定浅色或深色。

语言

手动翻译和截图翻译共用这里的默认语言。

快捷键

点进输入框后按组合键。Esc、Backspace 或 Delete 清空。

启动

登录系统后是否自动打开 OpenTranslate。
